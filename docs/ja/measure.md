# 実ゲームでの複数ラン計測（勝率検証）

実ゲームで**複数ランを自動で回して**、勝敗・到達階・所要時間・停止理由を記録します。
少数試行の勝率は参考値で、論文の結果と同等には扱いません。

## 使い方

```bash
# ゲームを閉じた状態で
./play.sh measure --runs 10

# seed を指定して回す
./play.sh measure --seeds ABC123,XYZ,DEF456

# 記録済みの集計だけ見る
./play.sh measure --summary
```

1 ランごとに、推論サーバを立てて `--autostart "DEFECT|0|<seed>"` を送り、Steam 経由でゲームを起動し、
サーバが 1 ランを終える（`done`）まで待って、ゲームを閉じます。

## 記録されるもの

`~/.local/share/sls2/runs/measure.jsonl` に 1 行 1 ラン（追記）。

| 項目 | 内容 |
|---|---|
| `seed` | そのランの seed |
| `character` / `ascension` | キャラとアセンション |
| `game` | ゲームのバージョン（例 v0.111.1） |
| `mod_version` | MOD をビルドした版 |
| `model` | 推論に使ったキャラ（hello の値） |
| `win` | 勝敗（完走時のみ） |
| `floor` | 到達階 |
| `actions` | 意思決定の数 |
| `seconds` | 所要時間 |
| `result` | `finished`（ゲームオーバー/勝利まで）/ `stalled`（安全停止などで止まった）/ `timeout` / `game exited` / `crash` |
| `reason` | 停止理由（自動停止のメッセージを含む） |
| `started` | 開始時刻 |

**止まったランも隠さず記録します**（`result` が `stalled` などになります）。分母から外しません。

## 注意

- 実行中はゲームを操作しないでください（クリックすると AI と競合します）。
- 1 ランあたりの上限は既定 900 秒（`--timeout`）。超えたら `timeout` として記録して次へ進みます。
- 途中で止めた場合、そのランは記録されません（終わったランから順に追記されます）。
- 画面のない環境（リモートデスクトップを閉じる等）でも動きますが、GPU/描画が止まると
  ゲームが進まないことがあります。その場合は `stalled` / `timeout` として残ります。

## 検証記録

`./play.sh measure --summary` の出力を、そのまま結果として残してください
（例: 10 件中完走 8、勝利 0、平均到達階 12.3）。ランごとの生データは JSONL に残ります。
