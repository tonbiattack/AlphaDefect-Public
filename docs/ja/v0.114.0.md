## 1. 何が入ったか（upstream の同期で追加されたもの）

- `game-v0.114.0/` が追加された（2026-11-25 の公開ベータ向けに、v0.113.1 の `engine/`・`python/`・
  `tools/` を適応したもの。出典: `game-v0.114.0/README.md`）
- 記録（中国語）は `zh/游戏更新v0.114.0/`（更新内容の棚卸し・適応レポート・影響評価・差分 TSV）

upstream README から読み取れる主な変更:

| 項目 | 内容 |
|---|---|
| 愚者のカード | OPTIMISM 追加、TWIN_SHOT が RAPID_SHOT の別名に（語彙 2,557→2,559、**旧 ID は不変**） |
| ダメージ計算 | ダメージプレビューがブロック・HP 減少フック（Hardened Shell, Hard to Kill, Slippery, The Boot）を含むようになった。観測は v0.113.1 基準に保つため `Engine/Obs/RawPreview.cs` で調整 |

| モデル | **v0.114.0 で学習した公開モデルは無い**。既存チェックポイントを特徴量再整列つきで使う |

## 2. ローカル基盤への組み込み（今回やったこと）

`local/versions.py`:

- `v0.114.0` を独立した版として追加（`tree="game-v0.114.0"`、`catalog="v0.114.0"`）
- キャラは 6 人（FOOL/IRONCLAD/NECROBINDER/DEFECT/SILENT/REGENT）だが、**全員 `untested`**
- `search=False`（sts2-sim 未対応）
- v0.113.1 への無条件フォールバックはしない（`PATCH_COMPAT` に追加していない）

回帰テスト（`local/tests/test_versions.py`）:

- `v0.114.0` の行がある・探索なし・6 キャラ・パッチ別名ではない
- 6 キャラすべて `untested`（`require_character` は `--allow-untested` が必要）

## 3. 未検証・ブロッカー

| 項目 | 状態 |
|---|---|
| **ローカルに v0.114.0 のゲームが無い** | Steam のインストールは v0.111.1 のまま。`local/data` のゲーム DLL も v0.111.1 |
| ヘッドレス build / selfcheck | **未検証**（ゲーム DLL の版が違うため、v0.114.0 のエンジンをビルドしても参照 DLL が一致しない） |
| モデルロード | 未検証（語彙 2,559・観測形式 26/27/29 の再整列が必要） |
| 実ゲーム Mentor 観戦 | 未検証（ゲーム版・MOD 版が v0.114.0 向けに揃っていない） |
| 勝率 | **未測定**（v0.114.0 で学習したモデルは無く、旧版の勝率を流用しない） |

v0.114.0 を試すには、利用者側で Steam のベータ版に切り替え（v0.114.0）、
`game-v0.114.0` のツリーで `python -m local setup` 相当のゲーム資産取得・ビルド・selfcheck を行う必要があります。
**セーブや Steam の設定はこちらから変更しません。**

## 4. 次の手順（v0.114.0 環境が用意できたら）

1. `local selfcheck`（v0.114.0 の DLL でエンジンをビルド）
2. `local play --character FOOL --allow-untested` で 1 局（語彙・観測の整合を確認）
3. `local mentor --character FOOL --allow-untested` で実ゲーム 1 ラン
4. 行動忠実実行率・fallback・停止理由を `fidelity` 行で記録
5. 6 キャラは順次（#72 の対応表と共通化）
