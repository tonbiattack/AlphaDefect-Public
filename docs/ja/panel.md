# ゲーム内操作パネル（速度・停止・1 手・手動切り替え・確認）

観戦中にゲーム画面を離れずに、速度・停止・1 手実行・手動への切り替えができます。
パネルは画面左上（HP などの上部バーのすぐ下）に出ます。`−` で折りたたみ、`×` で隠せます
（隠したあとは F6 で戻せます）。

```text
┌──────────────────────────────────────────────┐
│ AI自動 実行中 1x 接続                     − × │
│ 推奨: [3] 结束回合 p=1.000                    │
│ 一時停止  手動にする  1手  確認  戦闘終了で停止│
│ 速度 0.25x 0.5x 1x 2x 5x 10x                 │
│ 間隔 既定 0.5s 1s 2s 5s                      │
└──────────────────────────────────────────────┘
```

## 1. ボタン

| ボタン | 動き |
|---|---|
| **一時停止 / 再開** | AI の行動を止める／再開する。ゲーム自体は止めない（アニメーションは進む） |
| **手動にする / AIにする** | 手動では AI が一切操作しない（カード・報酬・経路も触らない）。ゲームはそのまま遊べる |
| **1手** | 1 つの意思決定だけ実行して、また止まる |
| **確認** | 各判断の前に自動で止まり、推奨と候補を表示して、許可（1手／再開）まで実行しない |
| **戦闘終了で停止** | 戦闘が終わったところで自動停止する（カード報酬を見たいときなど） |
| **速度 0.25x〜10x** | ゲーム全体の演出速度（Godot の `TimeScale`）。いつでも即時変更 |
| **間隔 既定/0.5s/1s/2s/5s** | AI の行動間隔。速度とは独立（じっくり観察したいときは速度 0.5x ＋ 間隔 2s など） |

## 2. キーボード

| 既定キー | 動作 |
|---|---|
| `F6` | パネルの表示／非表示 |
| `F7` | 一時停止／再開 |
| `F8` | 1 手実行（確認待ちがあればそれを実行） |
| `F9` | 自動／手動の切り替え |
| `F10` | 確認モードの切り替え |
| `Alt+[` / `Alt+]` | 速度を 1 段階下げる／上げる |

`mods/AlphaDefectAutopilot/keys.json` で変更できます。`"enabled": false` で全部無効。

```json
{
  "enabled": true,
  "hide": "F6",
  "pause": "F7",
  "step": "F8",
  "mode": "F9",
  "confirm": "F10",
  "speed_down": "Alt+BracketLeft",
  "speed_up": "Alt+BracketRight"
}
```

修飾キーは `Alt+` / `Ctrl+` / `Meta+` が使えます。キー名は Godot の `Key` 名（`F7`、`BracketLeft`、
`P` など）。ゲーム側のショートカット（数字キー・E など）と重ならない既定にしてあります。

## 3. 端末・HTTP からも同じ操作

パネルとサーバは状態を同期します（パネルの操作はサーバの `/status` に出て、
サーバからの操作はパネルの表示に反映されます）。

```bash
./play.sh launch --pause            # 一時停止
./play.sh launch --resume
./play.sh launch --set-speed 2
curl -s http://127.0.0.1:18766/status
curl -s -X POST -d '{"command":"step"}'        http://127.0.0.1:18766/control
curl -s -X POST -d '{"command":"manual"}'      http://127.0.0.1:18766/control
curl -s -X POST -d '{"command":"confirm on"}'  http://127.0.0.1:18766/control
curl -s -X POST -d '{"command":"pacing 1500"}' http://127.0.0.1:18766/control
curl -s -X POST -d '{"command":"stopcombat on"}' http://127.0.0.1:18766/control
```

`./status` の 1 行にも `パネル 自動・停止・確認・間隔1500ms` のように出ます。

## 4. 安全側の作り

- **古い応答を実行しない**: 手動切り替え・停止・1 手実行のたびに世代（epoch）を進め、
  それ以前に送った判断の応答は捨てます（ログに `stale action dropped`）。
- **再開時は状態を取り直す**: 再開すると保留中の判断は破棄され、いまの画面から合法手を作り直します。
  古い seq・候補番号・キャッシュでは操作しません。
- **通信断は手動と同じ扱い**: 接続が切れると行動を止め、パネルは「未接続」表示になります。
  つなぎ直すと、サーバが停止・手動・確認などの設定を送り直します。
- **速度の復元**: 停止・切断時は `TimeScale` を 1 に戻します（ログ `TimeScale restored to 1`）。
- **1 意思決定の境界**: 「1 手」は 1 つの Decision（カード 1 枚・報酬 1 つ・経路 1 つなど）です。
  選牌が複数段階に分かれる場合は、ゲームが 1 段階ずつ要求するので、それぞれが 1 手になります
  （アニメーションや確認待ちは手に数えません）。

## 5. 制限（既知）

- 確認モードの「1手」は、選ばれた行動が実際に画面を進めない場合（例: マップ画面が開いていない
  ときの経路投票）は、同じ状態のまま止まります。ログに `step done: paused again` が出ます。
  この場合は手動で操作するか、`resume` で進めてください。
- パネルは文字だけの簡易表示です（候補の強調や理由の表示はありません）。
- 外部から操作したときの反映は数十ミリ秒遅れることがあります（状態は 1 フレームごとに同期）。

## 6. 検証記録（2026-11-25、ゲーム v0.111.1）

| 確認 | 結果 |
|---|---|
| パネルの表示 | 画面左上（上部バーの下）に表示。`−`/`×` で折りたたみ・非表示 |
| 一時停止 | 行動数が 170 で停止（5 秒間変化なし） |
| 1 手実行 | 171 に 1 だけ増えて再停止 |
| 手動切り替え | 6〜14 秒間、行動数が増えない（ゲームは進行） |
| 自動に戻す | 171 → 184 と再開 |
| 速度 | 5x / 0.5x を即時反映（`speed=5`、`speed=0.5`） |
| 間隔 | 5000ms 指定で 16 秒間に 4 手（既定より明確に遅い） |
| 確認モード | 次の判断で停止し、推奨を表示（`confirm: waiting for approval`） |
| 速度の復元 | `stop` で `TimeScale restored to 1`、以後は未接続表示で停止 |

未検証: 実際にキーを押しての動作（F6〜F10・Alt+[ ]）。パネルのボタンは Godot の `Button.Pressed`
を呼ぶだけで、HTTP と同じ `PanelState.Apply` を通ります（そこは実機で確認済み）。
